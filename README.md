# Custom React Form

This is a minimal React application demonstrating custom form handling with validation and accessible markup.

Files added:
- `package.json` - project metadata and scripts
- `public/index.html` - app entry HTML
- `src/index.js` - React entry
- `src/App.js` - App shell wiring the form
- `src/components/CustomForm.js` - the form component (controlled inputs, validation)
- `src/index.css` - simple styles

Getting started

1. Install dependencies:

```powershell
npm install
```

2. Start the dev server:

```powershell
npm start
```

Notes
- This scaffold uses `react-scripts` for simplicity. You can adapt to Vite, Next.js, or your preferred toolchain.
- The form demonstrates client-side validation and shows submitted JSON below the form.
